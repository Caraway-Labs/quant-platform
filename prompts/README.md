# Reusable prompts

Use prompts as review aids, subordinate to the issue, [AGENTS.md](../AGENTS.md), and the owning repository's instructions.

## Issue intake

> Read the governing issue and repository catalog. Identify the owning repository, acceptance criteria, dependencies, contracts, security boundaries, tests, and unresolved questions. Do not edit files yet.

## PR review

> Compare the diff with every acceptance criterion. Check repository ownership, point-in-time semantics, contract compatibility, secret handling, risk veto, paper-first behavior, test evidence, and accidental files. Report actionable findings with file locations.
