# Development

Start with the issue specification and [AGENTS.md](../../AGENTS.md). Route the change through the [catalog](../../repositories.yaml), list acceptance criteria and dependencies, branch in the owning repository, implement, test, inspect the diff, and submit a reviewable PR. State the exact checks run and any evidence still missing. Use [Git workflow](../../standards/git-workflow.md) and [testing standard](../../standards/testing.md).
